# Easy Author Avatar Image

## Description

Easy Author Avatar Image is a WordPress plugin that allows site administrators and users to easily upload and manage custom avatar images for author profiles. This plugin replaces the default WordPress avatar with a personalized image, enhancing user profiles and author boxes across your site.

## Features

- Upload custom avatar images for users
- Supports multiple image formats
- Integrates with WordPress user profile page
- Option to display avatars in comments, posts, and author boxes
- Fallback to default avatar if no custom image is set
- Lightweight and easy to use

## Installation

1. Download the plugin and unzip the file.
2. Upload the `easy-author-avatar-image` folder to the `/wp-content/plugins/` directory.
3. Activate the plugin through the 'Plugins' menu in WordPress.
4. Go to your user profile to upload or change your avatar image.

## Usage

- Navigate to **Users > Your Profile**.
- Use the avatar upload section to select and save your custom image.
- The new avatar will appear wherever your author image is displayed.

## Frequently Asked Questions

**Q: Can I revert to the default avatar?**  
A: Yes, simply remove your custom image from your profile.
